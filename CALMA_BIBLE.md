# 1. PROJECT VISION

CALMA — это не просто поставщик замороженных круассанов.

Весь сайт выглядит как огромная пекарня.

Пользователь словно уменьшился и наблюдает за маленькими пекарями, которые работают внутри огромного производства.

Персонажи не декоративные.

Они обслуживают интерфейс сайта.

* этот документ

# 3. WORLD RULES

Мир CALMA строится по следующим правилам.

Все предметы большие.

Пекари маленькие.

Пример:

* огромная коробка
* огромный круассан
* огромная печь
* огромный мешок муки

Пекари примерно 1/8 размера предметов.

# 19. DEVELOPMENT PRINCIPLE

Персонажи не являются украшением.

Они работают.

Они помогают пользователю.

Они взаимодействуют с интерфейсом.

Они появляются только тогда, когда это усиливает UX.

Интерфейс и персонажи — единый мир CALMA.
